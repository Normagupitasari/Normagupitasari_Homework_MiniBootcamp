# 🧪 Selenium WebDriver Automation – SauceDemo

Project ini berisi automation test sederhana menggunakan **Selenium WebDriver (JavaScript)** untuk melakukan pengujian pada website [SauceDemo](https://www.saucedemo.com).

---

## 📂 Test Cases Implemented

1. **Visit SauceDemo & Check Page Title**  
   - Membuka website `saucedemo.com`  
   - Verifikasi page title = **"Swag Labs"**

2. **Check Login Button**  
   - Mengecek apakah tombol **Login** muncul di halaman

3. **Login SauceDemo**  
   - Input username `standard_user`  
   - Input password `secret_sauce`  
   - Klik tombol login  
   - Berhasil masuk ke halaman produk

4. **Sort Products (Z → A)**  
   - Login terlebih dahulu  
   - Pilih dropdown **Product Sort Container**  
   - Urutkan produk berdasarkan **Name (Z to A)**  

---

## 🛠️ Tools & Frameworks

- **Language:** JavaScript (Node.js)  
- **Testing Framework:** Mocha  
- **Assertion Library:** Assert  
- **Automation Library:** Selenium WebDriver  
- **Browser:** Chrome
